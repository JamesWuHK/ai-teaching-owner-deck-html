# AI Teaching Owner Deck HTML

## 生成 HTML

```bash
npm run build:deck-html
```

输出文件：

`ppt/ai-teaching-owner-deck-html/index.html`

## 本地预览

直接打开：

```bash
open ppt/ai-teaching-owner-deck-html/index.html
```

或者启动本地静态服务：

```bash
python3 -m http.server 4173 --directory ppt/ai-teaching-owner-deck-html
```

然后访问：

`http://127.0.0.1:4173`

## 测试

```bash
npm run test:deck-html
```
